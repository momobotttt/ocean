ScorePlay — 預測積分遊戲（前台 + 管理後台）
純積分遊戲，唔涉及任何金錢交易或真實投注。

────────────────────────────────────
點行（喺電腦/ Mac）
────────────────────────────────────
1. 裝 Node.js（如未裝）：https://nodejs.org （揀 LTS）
2. 打開「終端機 Terminal」，去到呢個資料夾，例如：
      cd ~/Downloads/scoreplay-app
3. 第一次行，裝相依套件：
      npm install
4. 啟動：
      npm start
   （或 node server.js）
5. 瀏覽器打開：
      玩家：  http://localhost:3000
      後台：  http://localhost:3000/admin
            預設管理員  admin / admin123  （登入後請改密碼）

────────────────────────────────────
有咩功能
────────────────────────────────────
玩家（前台）
  • 註冊 / 登入（新玩家送 1,000 積分）
  • 主頁睇即場 + 即將開賽，賠率每幾秒自己浮動、即場比分跳動
  • 撳賽事睇詳情（勝負 / 讓球 / 大細盤口）
  • 揀賠率 → 投積分落「預測單」
  • 排行榜、我的預測紀錄、積分結餘

管理後台（/admin）
  • 賽事 / 賠率：新增、編輯、刪除賽事，設 1X2 / 讓球 / 大細 賠率，設即場
  • 入比分 / 開賽果：開賽果會自動結算 1X2 預測派彩（讓球/大細示範版可手動調分）
  • 用戶 / 積分：睇排行榜、所有用戶、手動加減積分
  • 公告：改首頁 banner

────────────────────────────────────
資料
────────────────────────────────────
• 所有資料存喺同一個資料夾嘅 data.json（第一次行會自動建立 + 種子賽事 + admin 帳戶）
• 想清空重來：刪咗 data.json 再 npm start
• 伺服器每 3 秒會自動浮動「即場」賽事嘅賠率同比分，營造真實感

技術：Node.js + Express + JSON 檔案儲存（零資料庫設定）。原創程式碼。
上線部署（之後）：可放上 Render / Railway / 自己 VPS，再講。
